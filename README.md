# رحلة تعلم الإسلام — To-Do List

هذا المشروع يحول منهج تعلم الإسلام إلى لوحة تقدم تفاعلية.

## التشغيل
افتح `index.html` في المتصفح مباشرة.

## المميزات
- 8 مراحل دراسية.
- دروس قابلة للتعليم كمنجزة.
- شريط تقدم عام.
- تقدم منفصل لكل مرحلة.
- حفظ تلقائي باستخدام `localStorage`.
- زر لإعادة ضبط التقدم.
- تصميم Responsive يعمل على الكمبيوتر والموبايل.

1. من هو الله؟

4. سيرة النبي ﷺ.
5. الحديث والسنة.
6. الفقه والعبادات.
7. الأخلاق وتزكية النفس.

ملاحظة: المنهج عبارة عن خارطة تعلم وليس فتوى أو بديلًا عن سؤال عالم موثوق في المسائل الفقهية التفصيلية.
